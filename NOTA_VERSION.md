# Nota técnica de versión de GlowCare

## Identificación

Versión documental inicial 0.1.0.
Fecha: 11 de octubre de 2026.
Etapa: planificación, análisis y diseño.

## Contenido de la versión

Esta versión reúne las evidencias técnicas de las semanas II a VII: planificación, requisitos funcionales y no funcionales, historias de usuario, trazabilidad, cinco diagramas UML, arquitectura por capas, seguimiento de tareas, riesgos y comunicación con interesados.

Incluye el README actualizado con el objetivo, problema, funcionalidades previstas, herramientas, estado actual y organización propuesta del frontend y backend. También contiene el registro de cinco avances en CHANGELOG.md.

La versión corresponde a la documentación del proyecto. No contiene una aplicación ejecutable.


## Cambios controlados

La creación de la carpeta docs, la incorporación de las evidencias, la actualización del README y la creación del registro de avances se guardaron mediante commits en la rama main.

En GitHub Issues se completaron las descripciones de las tareas #5, #14, #15 y #16 con actividades pendientes, riesgos y criterios de finalización.

En GitHub Projects se ajustaron las tareas de autenticación, esquema de base de datos y prototipo a Por hacer. La documentación inicial #7 se cerró como completada y se ubicó en Finalizado.

Los commits conservan el historial de los archivos. Los Issues y el tablero registran los cambios de seguimiento.
